# Rule index

One convention per file in `docs/rules/`. **Route from this table, read only what it
names, stop.** Reading the corpus is a bug, not diligence.

Each rule file starts with YAML frontmatter:

```yaml
---
id: turbo-status                      # filename without .md
title: ...                            # one line
applies_to: ["app/controllers/**"]    # globs — if you are editing a match, the rule applies
triggers: ["form frozen", "422"]      # grep these when routing by symptom
see_also: ["controllers"]             # other rule ids
tokens: 430                           # read cost, generated by bin/doc-tokens
current_state: matches                # or `diverges`, when the code does not obey it yet
---
```

So `grep -l "<keyword>" docs/rules/*.md` finds a rule by symptom without loading
anything.

Know the symptom but not the file? [`SYMPTOMS.md`](SYMPTOMS.md) — the symptom table and
the full annotated list. It costs more than this page; come here first.

## Then, only what you are actually doing

The rows above are what applies to *any* edit in that path. These are conditional —
read one when the work touches it, not because you opened a file of that type.

| Editing a view or component, and you are… | Also read |
|---|---|
| writing a form, or rendering errors | [forms-ui](forms-ui.md) |
| rendering a collection that can be empty | [empty-states](empty-states.md) |
| building class names in Ruby or JS | [tailwind-build](tailwind-build.md) |
| iterating records, or adding an association call | [n-plus-one](n-plus-one.md) |
| adding a Turbo frame, or debugging "content missing" | [turbo-frames](turbo-frames.md) |

**Read cost:** this index (~1500) plus one or two rules (240–1150) ·
[`SYMPTOMS.md`](SYMPTOMS.md) (~2300) only when routing by path missed. Every `tokens`
figure is generated from the file by `bin/doc-tokens` — budget from it, and re-run that
script after editing a rule.

Adding, renaming, or deleting a rule means updating this table **and**
[`SYMPTOMS.md`](SYMPTOMS.md); `id` and filename must match. Decisions live in
[`../adr/`](../adr/), not here.
